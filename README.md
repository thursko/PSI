# Problème Scientifique et Informatique
Problème du voyageur de commerce - logiciel d’optimisation de tournées

  TourneeFutee/ : Fichiers sources de l'application.

  TourneeFutee.Tests/ : Suite de tests unitaires (fournis par l'école).

  init_db.sql : Script d'initialisation de la base de données MySQL.

  • Calcul de tournées optimales

  • Persistance en base de données
